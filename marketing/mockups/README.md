# Marketing mockups

Generated by `scripts/make_marketing_mockups.py` from **unedited app screenshots**:

- `m*.png` captures from the iOS Simulator (`--marketing` flag: the labelled **Demo world** of synthetic sample adventures, no simulator banner) published by a manual run of the iOS build workflow to the `ci-screenshots` branch.
- `m9`–`m11` help-chat captures (Simulator has no AI, so these show keyword routing, labelled in the footnote).
- `iphone-coach.png`: a real iPhone 12 Pro Max screenshot of the on-device AI coach card on the demo world (from the founder's phone, 2026-10-09).

Files:
- `*-portrait.jpg` (1080×1350) and `*-story.jpg` (1080×1920): one phone per screen with a headline and a source footnote.
- `hero-landscape.jpg` (1920×1080): three phones.
- `store-1..6.jpg` (1290×1500) and `store-strip.jpg`: App Store-style panels (realistic frames, tilted pair, bleed).

Screens show sample data where labelled ("Demo world", SAMPLE). Do not retouch screen content; regenerate instead:
`git fetch origin ci-screenshots && git --work-tree=/tmp/shots checkout origin/ci-screenshots -- . && python3 scripts/make_marketing_mockups.py /tmp/shots`
