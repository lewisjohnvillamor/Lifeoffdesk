# Life Off Desk — build skills and handoff

## Focused reusable skills

| Skill | When to invoke | Purpose |
| --- | --- | --- |
| `$life-off-desk-ios` | Building or reviewing walking, map reveal and persistence | Preserve true GPS, offline starter geometry, session state and device acceptance |
| `$life-off-desk-local-ai` | Integrating or testing AI suggestions | Prove iPhone inference, validate intent and ground suggestions in real records |
| `$life-off-desk-brand` | Styling screens or preparing mascot assets | Apply approved tokens, native iPhone behavior and canonical male cat |

These skills are project-specific guidance. They do not install Xcode, run a model or provide place data. Their source of truth is current project decisions; explicit new user decisions override old skill defaults.

Recommended existing capabilities when needed: official Apple/runtime documentation for changing APIs; win-hackathon for sprint/rule/demo planning; Figma SwiftUI and design-to-code skills only when actually implementing a Figma design; imagegen for requested raster edits; ordinary Git/code verification for implementation. Avoid invoking unrelated skills merely because installed.

The three custom skills were authored, structurally validated and scenario-reviewed, but the Skills service rejected installation with HTTP 422. They are not confirmed installed. Portable copies are now committed under skills/. On your Mac, ask your coding agent to read the relevant skills/<name>/SKILL.md directly. AGENTS.md and repository docs carry the same build rules. Automatic installation/discovery in any particular client is not assumed.
