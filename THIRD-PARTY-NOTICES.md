# Materials and tool disclosure

- Planning assistance: ChatGPT/Codex; project plans, reference board and mascot stickers came from the conversation. Reference images were AI-generated using the founder's supplied visual direction/personal cat. Original personal photos are excluded from this repository.
- App implementation: Swift/SwiftUI app, core library, scripts, tests and docs written 2026-10-09 with Claude Code (Anthropic) during the hackathon. Built in Xcode/CI and run on the founder's iPhone 12 Pro Max; see docs/BUILD-STATUS.md for what was verified and how.
- Build tooling: XcodeGen (MIT) generates the Xcode project from LifeOffDesk/project.yml; not vendored.
- Engine: llama.cpp b11429 iOS XCFramework from ggml-org, MIT; preserve upstream license/notices with distribution. Pinned release downloads are listed in config/materials-lock.json.
- Model: Qwen3-1.7B Q4_K_M GGUF, ggml-org quantization of Qwen3, Apache-2.0 (https://huggingface.co/ggml-org/Qwen3-1.7B-GGUF), pinned by commit and SHA-256 in config/materials-lock.json. Qwen3-0.6B Q4_0 (same publisher/license) was evaluated earlier and is no longer bundled. Preserve upstream licence/notices with distribution.
- Apple system frameworks (on-device): SwiftUI, CoreLocation, Vision (`VNGenerateForegroundInstanceMaskRequest` for sticker cut-outs, `VNClassifyImageRequest` for help-chat photos), Speech (on-device recognition only), PhotosUI, CryptoKit, Network.
- Help cards (`StarterData/safety-guide.json`) are paraphrased from the public sources each card links (NHS, St John Ambulance, WHO, The AA, GOV.UK and others). Hotlines (`StarterData/hotlines.json`) come from the official pages listed per entry, checked 2026-10-09; entries marked secondary come from a news report.
- Launch film (`marketing/video`): Remotion (free license for individuals and companies with up to 3 employees; larger for-profit companies need a company license), FFmpeg, Inter font (SIL OFL 1.1, via @fontsource/inter). Music "Just Keep Walking" by Michael Ramir C. and stock clips 42653 and 4871 from Mixkit, used under the Mixkit Free License (commercial use and social posts allowed, no attribution required). The raw media files are not redistributed in this repository.
- CI: GitHub Actions macOS runners build, test and capture Simulator screenshots; no runtime role.
- No cloud AI API or runtime network service is used by the app.
- Map/place data: OpenStreetMap contributors, ODbL. The bundled LifeOffDesk/Resources/StarterData/*.json files are a derived database of OSM data (retrieved 2026-10-09 via the overpass.private.coffee Overpass mirror) and are made available under ODbL with attribution shown in the app. Preparation script records source IDs/URLs, retrieval date and attribution. Source tags do not establish real-time access, hours or prices. Distribution/derived database obligations must be checked before release: https://www.openstreetmap.org/copyright .
- Figma: previous file remains unrevised; included update script is unapplied and runtime-untested. Latest static image is an illustrative reference.
